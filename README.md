## 1️⃣ CGPA Calculator

### 📌 Description
The CGPA Calculator computes a student’s Cumulative Grade Point Average (CGPA) based on the number of courses and grades earned in each. It calculates total credits, total grade points, semester GPA, and overall CGPA.

### 🛠️ Features
- Add multiple courses with credit and grade
- Calculate total grade points
- Compute GPA and CGPA
- Display course-wise breakdown

### ▶️ Usage
Run the program and input:
- Number of courses
- For each course: credit and grade

## 2️⃣ Sudoku Solver

### 📌 Description
This program solves any valid 9x9 Sudoku puzzle using the backtracking algorithm.

### 🛠️ Features
- Solves standard Sudoku puzzles
- Uses efficient backtracking
- Validates entries to follow Sudoku rules

### ▶️ Usage
Modify the initial `grid[9][9]` in `main()` with your puzzle (use 0 for empty cells). The program will display the solved board.

## 3️⃣ Banking System

### 📌 Description

### 🛠️ Features

- Transfer money between accounts
- View customer details and transaction history

### ▶️ Usage

- View account and transaction history
